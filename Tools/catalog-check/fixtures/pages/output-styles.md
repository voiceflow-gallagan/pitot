# Output styles

> Synthetic test page for catalog-check. It copies the layout of the output styles page, not its text. The style names are real, the descriptions are written for this test.

Set the `outputStyle` key in a settings file, or run `/config`, to pick a style.

## Built-in output styles

| Style | What changes |
| :- | :- |
| **Default** | Nothing |
| **Explanatory** | Adds short notes on why |
| **Learning** | Leaves small tasks for you |
| **Concise** | Shorter answers |
| **Proactive** | Suggests next steps |

## Custom output styles

Put a markdown file in `~/.claude/output-styles/` to add your own style.
